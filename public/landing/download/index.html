the two minute guide

what you need.

mac
macos 12 or later. apple silicon or intel.
windows
windows 10 or 11, 64-bit.
linux
ubuntu 24.04, 64-bit, with the gnome desktop. a .deb or an appimage. in beta.
an ai
an account with claude, chatgpt, gemini, grok or another ai you use. an api key or a local model works too.
phone app
an iphone or an android phone, and a dusk bot running somewhere to pair it with.
your own server
optional. ubuntu 22.04 or 24.04 with 2 gb of memory or more.

check what you downloaded.

every release comes with a file called SHA256SUMS that lists the fingerprint of each installer. work out the fingerprint of the file you got and compare the two. they should match exactly.

the mac app is also signed and notarized, and the app only ever tells you about an update that carries our release signature. you choose when to install it.

mac

shasum -a 256 ~/Downloads/DuskBot.dmg

windows (powershell)

Get-FileHash $HOME\Downloads\DuskBot-setup.exe -Algorithm SHA256

linux

sha256sum ~/Downloads/DuskBot-amd64.deb

or run it on your own server.

keep your bots on a server you rent, so they stay on when your computer is off. in the app, open the menu at the top of the sidebar and add your own server. it shows one line. paste it on the server and it installs everything and links itself to your app, in about ten minutes.

how your own server works

the line looks like this. the app fills in your one-time code

curl -fsSL https://dusk.bot/install.sh | sh -s <code>

to read the installer before you run it

curl -fsSLo install.sh https://dusk.bot/install.sh
curl -fsSL https://dusk.bot/install.sh.sha256
shasum -a 256 install.sh
less install.sh
