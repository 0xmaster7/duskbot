chatgpt agent is gone: compare work with a team of bots

as of 12 november 2026, openai's help page says chatgpt agent is no longer available.1 openai points people to chatgpt work for longer, multi-step tasks and finished deliverables. work is therefore the current option to compare with dusk bot. stay with work if you want tasks inside chatgpt; consider dusk if you want separate bots with individual jobs, memory and ai choices. work can also run locally in the desktop app, so cloud versus local is not the dividing line.

by the dusk bot team · checked 12 november 2026 · how we made this

the short version

pick chatgpt work if

  • you want to choose work inside chatgpt rather than organise a separate bot app
  • you want openai models and chatgpt plan usage in one product
  • you want its documented web, mobile and desktop options, including local desktop work

pick dusk bot if

  • you want different named bots, each with its own job, chats and memory
  • you want to change the ai per bot while keeping that bot's chats, files and memory
  • you want several bots in one group thread, with a leader or mentions deciding who answers

check whether the guide you found is about the retired product

openai's agent help article now says agent is no longer available and directs readers to work.1 an older review about choosing agent mode can still describe something that used to exist. start with the current work instructions when deciding what to buy or how to begin.2

this also changes the alternatives question. you do not have to leave chatgpt simply because agent was retired. work is the first option to evaluate if you want longer tasks there. the dusk versus chatgpt page is useful if you want to stay focused on those two choices.

local files are not a dusk-only feature

openai's work help page documents cloud use on web and mobile and local work through the chatgpt desktop app, including local files, apps and browser.3 it would be misleading to describe work as only a remote browser.

dusk's difference is that each bot is its own helper with one job. a bot has its own job, chats and memory, and can keep several threads. you can switch its ai without losing those chats, files or memory.9 a group chat brings several bots together; each retains its own ai and permissions.13

try a document brief before a large project: "read these attached planning notes. prepare a decision brief with the options, the evidence in each file and the questions i still need to answer." dusk supports document attachments.12 check the brief against your notes yourself.

budget shared usage, not old monthly message caps

openai's current docs say work and codex share pricing, credits and usage limits.4 do not turn an old agent message cap into a promise about how much work you can do today. openai's pages we read don't give a fixed number of work tasks per plan.

as of 12 november 2026, the documented usd plan figures include plus at $20/month and pro at $100, $200 or $500/month. local prices may differ.56 dusk cloud hosting is a separate bill from ai usage, which your provider charges.810 neither headline price proves which will be cheaper for your workload.

if recurring work is the reason you arrived here, read the chatgpt scheduled tasks guide with the product change in mind. dusk routines on your own computer also need the app running and the computer awake; dusk cloud runs them on time.14 check your ai provider's current terms before depending on a sign-in for ongoing work.

questions

what happened to chatgpt agent mode?

as of 12 november 2026, openai's help article says chatgpt agent is no longer available and directs readers to chatgpt work for longer, multi-step tasks and finished deliverables.1

can i use the replacement on my iphone?

the current work help page lists ios and android as well as web and macos and windows desktop apps. the desktop app also supports local work; phone and web work run in the cloud.3

how many work tasks do i get with plus or pro?

openai's help pages say work shares usage, pricing and credits with codex, but they don't give a fixed number of tasks per plan. check current plan limits rather than relying on a retired agent-mode allowance.4
