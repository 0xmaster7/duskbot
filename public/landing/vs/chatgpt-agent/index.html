chatgpt agent is gone: chatgpt work vs dusk bot

chatgpt agent is no longer available. openai now points people to chatgpt work for longer, multi-step tasks and finished deliverables.1 this page compares work with dusk bot. work keeps that work inside chatgpt, with cloud use on web and mobile and a local option in the desktop app.2 dusk bot gives you separate named bots and a choice of ai per bot. start with where the work should happen and which usage bill it belongs on.

by the dusk bot team · checked 12 november 2026 · how we made this

the short version

pick chatgpt work if

  • you want finished multi-step work inside chatgpt with openai models
  • you already organise tasks around work and codex, and are comfortable with their shared usage

pick dusk bot if

  • you want separate bot roles that keep their own memory and chats
  • you want to choose models per role and move bots between your own computer, server and dusk cloud

the current choice, rather than the old agent limits

as of 12 november 2026, agent mode has been retired. old message quotas should not be treated as work allowances. the rows below concern the replacement unless explicitly stated otherwise.

an old agent tutorial can answer the wrong question

if you arrived looking for an agent-mode button, the current help article redirects you to work.1 choose work in chatgpt instead.3 cowork vs dusk bot covers another product whose name and experience are changing.

work's web and phone experience uses the cloud. the desktop app can also run work locally with files, apps and a browser.2 decide whether a task needs a file on your computer before assuming that every surface has identical access. check that the plugins you need work where the task runs.

count shared usage before counting schedules

openai says work and codex share usage, pricing and credits.4 if you use both, budget for both. a scheduled task slot is a limit on active tasks, not an allowance for unlimited runs or unlimited model work.

active-task limits and timing controls vary by plan; see the chatgpt scheduled tasks guide.5

dusk bot does not put ai usage on the dusk bill. a hosted dusk computer and an ai plan are separate costs, and a bot tells you if the ai plan runs out.811 use the ai agent cost guide to compare a whole month, not just the software price.

try a handoff you can check

a useful first request is: "turn the attached notes into a decision brief. separate agreed points from open questions and flag anything the notes do not support." review it beside the original notes. this checks whether the handoff suits you. a smooth answer isn't the same as a right one.

in dusk bot you can keep a reviewer bot and a separate planning bot, each with its own memory and job.11 keep the first try to files you attach. if you later connect apps, give a reviewer read-only access and set sending to Ask every time; a bot on Full access with no sending rule may otherwise send up to 25 a day without asking.1213

how we checked

we make dusk bot. this page uses openai's help and pricing pages as they read on 12 november 2026 and dusk bot docs. we did not run identical tasks, so there is no output-quality ranking. the scheduled-task caps below come from openai's task help page; they are not a promise about how much work a model can finish or a replacement for shared usage limits.

questions

does chatgpt work run on my own computer?

the desktop app can run work locally with files, apps and a browser. work on web and mobile runs in openai's cloud, as of 12 november 2026.2

can i use chatgpt agent on my iphone?

the replacement, chatgpt work, is available on ios and android as well as web and desktop. web and mobile work runs in the cloud.2 do not use an old agent-mode guide to infer current work quotas.
