claude code from your phone: three ways in

you can reach claude code from a phone in several ways. as of 12 november 2026, anthropic's remote control opens a window into a session on your computer, while its cloud sessions run elsewhere. with dusk, you text a bot whose engine is claude code. choose by where the work needs to live: your phone reaching a laptop does not keep that laptop awake.

by the dusk bot team · checked 12 november 2026 · how we made this

remote control keeps your existing machine involved

as of 12 november 2026, anthropic's remote control connects a claude code session on your own machine to claude.ai/code or the claude mobile app. the local process still does the work. the computer must stay on, and the claude process must remain running. if sleep or a lost network interrupts it, claude code reconnects when the machine comes back.1

that fits a session tied to the computer at your desk. it does not turn the phone into a replacement host. before leaving, think about power, connectivity and whether the machine will stay available long enough to finish.

anthropic lists remote control on pro, max, ultra, team and enterprise. api-key authentication is not supported for it; team and enterprise need an owner to enable the feature.1

cloud sessions are anthropic's separate option

as of 12 november 2026, anthropic documents cloud sessions that keep running when you close the laptop. you can start from the Code tab in its mobile app, claude.ai/code, the desktop app or claude --cloud. usage counts toward plan limits.2

the page lists pro, max, ultra and team, plus eligible enterprise seats. if the goal is a coding session you can check while travelling, read this option before setting up another computer. for repeating work rather than one session, the claude scheduled tasks guide explains its cloud scheduler. do not assume a session and a schedule are the same thing.

dusk gives you a bot to text

in dusk, a bot is a named teammate with a job, its own chats and memory, and an ai you pick. choosing claude code as the engine means dusk runs that official command-line app on the machine where the bot lives, with you completing sign-in yourself. texting the bot lets you give work and follow up through that chat.46

this fits ongoing work with a named bot, rather than a window into a particular terminal session. if you want one bot for planning and another for reviewing documents, they can have different jobs and different ais. each keeps its own memory. switching an ai does not discard the bot's chats or files.4

using a phone doesn't change anthropic's terms. its legal page (checked 12 november 2026) says nothing in it prevents 'an end user from signing in to the unmodified Claude Code binary with their own Claude subscription', and it sets conditions for platforms that host it. check the current page yourself.7

pair once, then test away from your desk

open dusk's phone pairing and scan the code. alternatives are a six-digit code, a nearby list on wi-fi or tailscale. pairing needs no account. iphone and android are supported, but the store apps are still on their way. for now, pairing opens dusk in your phone's browser and you add it to the home screen. that browser version sends no notifications.3

send a simple question while the host is awake. then check which host you paired to. if it is your laptop, Settings, Remote access, Keep this computer awake helps keep it reachable. if you need it after shutting the laptop, pair with dusk cloud instead.3

keeping claude code available overnight covers the hosting tradeoffs. for people looking specifically for other chat channels, the telegram, discord and slack guide is a separate question from phone pairing.

use the small screen for decisions

give a narrow instruction you can review on the phone: 'read the proposal i attached and tell me which two assumptions need checking. leave the file alone.' that gives you a useful checkpoint without asking you to inspect a whole document while walking.

dusk approval cards can reach the phone. connected apps can be limited per bot, including read-only access. for changes inside an app, write 'ask me before you change anything' if you want supervision. sending has a separate approval setting. one exception: a bot on Full access with no sending rule of its own may send up to 25 a day without asking, so set Sending on your behalf to Ask every time for full-access bots.8 do not treat phone access as a reason to grant broader permissions.8

questions

how are people running claude code from their phone?

as of 12 november 2026, anthropic offers remote control into a running local session and cloud sessions started from its mobile code tab. dusk offers chat with a bot backed by the ai you choose. the hosting choice is what decides whether the laptop may sleep.123

why does it stop working when i leave my laptop?

for remote control, the local claude process and computer must stay running. for dusk paired to that computer, dusk must also be open. check the host before troubleshooting the phone.13

do i need an app store download to pair dusk?

not yet. the store apps are on their way. use the paired browser version and add it to your home screen; keep in mind that this version does not send notifications.3
