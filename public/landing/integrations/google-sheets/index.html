a google sheets bot with a clear range to work in

connect google sheets and tell a bot in dusk bot which spreadsheet, tab and range to use. it can look up rows, update values and create charts through the connected app. choose your ai, then start with a small check in chat. cell edits are app changes, so use explicit instructions when you want to review them first.

by the dusk bot team · checked 12 november 2026 · how we made this

what a bot can do in Google Sheets

a spreadsheet request works better when the bot knows where the headers end and which cells hold formulas. these actions cover finding the right table, reading its structure and making a deliberately bounded update.

actiondusk bot treats it aswhat you would use it for
Search Spreadsheetsreadfind the tracker by title before touching a similarly named file
Get spreadsheet inforeadcheck the workbook structure before choosing a tab
Get sheet namesreadconfirm the current tab names rather than guessing
Look up spreadsheet rowreadfind the row for a particular order reference
Get Table Schemareadinspect the table columns before preparing new entries
Update spreadsheet valueschangewrite agreed values to a named destination range
Append Values to Spreadsheetchangeadd new records after existing entries instead of overwriting them
Create Chart in Google Sheetschangemake a chart from the range you selected

composio, the connection service dusk bot uses for apps, lists 58 Google Sheets actions (catalog version 20261101_00, read 12 november 20264). dusk bot treats 16 of them as reads, 0 as sends and the other 42 as changes. an action counts as a read only when its name starts with a read word like get, list or search, so a bot you allow only to read can never call the rest. a send is anything that reaches a person outside the app or moves money: it waits for your Allow unless you've given that bot a daily amount it may send alone.

connect Google Sheets

  1. open Connected apps in the sidebar.
  2. pick Google Sheets and sign in on Google Sheets's own page, so your password goes to them and never to a bot.
  3. choose which bots may use it, and whether each may only read or may also change things. your bookkeeper doesn't need your Google Sheets.
  4. ask in plain words. reading and drafting happen freely; sending asks you first.

in Connected apps, sign in to google sheets and allow your spreadsheet bot to use it. google receives the sign-in. paste the spreadsheet reference into chat and name the tab. for controlled updates, restrict the bot to the actions it actually needs rather than granting the entire catalog.

routines to copy

give a routine the column meanings as well as the schedule. the messages below use different sheets jobs: finding exceptions, adding entries and preparing a chart.

stock exceptions

each monday at 9, inspect the inventory tab in my acme stock sheet. compare available units with the reorder level on each row. report items below the level, with their row numbers. do not edit cells or sort the sheet.

mondays at 09:00 · a row-by-row reorder check in chat

intake rows

every weekday at 5, take the new requests i gave you in this thread today and prepare rows for the acme intake sheet. match its column names. show me the proposed rows and ask me before you change anything. do not overwrite existing requests.

weekdays at 17:00 · proposed intake rows, followed by an append only if you agree

weekly chart check

every friday at 2, inspect the weekly totals table in the acme sales sheet. tell me its covered dates and any empty weeks. propose a chart using only that table, and ask me before you change anything. leave source values alone.

fridays at 14:00 · a coverage check and a chart proposal

what it asks you first

updating a range, sorting rows and adding a chart are changes inside sheets. the sending rule does not promise an approval card for them. if you need a checkpoint, make "ask me before you change anything" part of the job.

per-bot app permissions can limit available actions before a call reaches google. one catch: sheets' find and replace action starts with "find", so dusk bot treats it as a read and a read-only bot can still call it, and it changes cells. give a sheets bot an exact action list without it. some lookup-like actions count as changes instead, so pick the exact actions you need.

what it cannot do

  • update, append or format cells when the bot has only read permission, with one exception: find and replace counts as a read in dusk bot today, so leave it off a read-only bot's action list.
  • choose a safe write range from an ambiguous instruction like "clean this up". identify the tab, headers and protected working area in your request; review the proposed edits first.
  • run a monday sheet check while the local app is closed. scheduled desktop work waits for the machine; a run missed by less than 12 hours runs once on return, and older runs are skipped.

make the handoff precise

say whether blank cells mean missing data or zero. tell the bot which columns contain formulas and must stay untouched. ask it to quote the source range alongside a result so you can inspect it. for a file dropped into chat rather than a connected google spreadsheet, see excel files.

a report is only as current as its source

a totals chart cannot tell you whether every transaction reached the table. if your question starts with billing records, read those through stripe before planning a sheet update. finding other source files may call for a separate google drive connection.

questions

can claude or chatgpt update my google sheet?

a bot in dusk bot can use the listed sheets actions with the ai you choose. it needs the connected account, permission for the write action and a clear destination range.

does it ask before changing a cell?

cell edits are not covered by the documented send approval rule. put an explicit ask-first instruction in the routine, and use restricted app access while checking it.

can it just tell me which rows look wrong?

yes. make the output a list in dusk chat, with row references and reasons. say that source values must remain unchanged.
