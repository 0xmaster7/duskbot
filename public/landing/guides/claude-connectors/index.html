claude connectors: connect the job you actually need

claude connectors let claude retrieve data and take actions in apps and services. anthropic lists them in its connectors directory, with use cases, read and write capabilities and availability. dusk bot has a separate connected-app flow through composio. decide which task needs access first, then connect the app in the product you will use. a connection in one product is not the setup for another.13

by the dusk bot team · checked 12 november 2026 · how we made this

what anthropic means by connectors

as of 12 november 2026, anthropic says web connectors are available to all users and work across claude, claude desktop, claude code and the api. the pricing page marks connectors as included on free, pro, max and ultra. check the individual directory entry for the connector's capabilities and availability.12

anthropic also describes custom connectors for services that support mcp. the mcp guide explains the standard. do not read a broad plan entitlement as a promise that every connector exposes every action in an app. the directory entry is the place to check the specific connection.

how dusk connected apps differ

dusk bot connects apps through composio. open Connected apps, sign in on the app's own page, then choose which bots may use the connection. each bot can have an app off, read only, or read and write, with an exact action list also possible. a bot set to read only can't make changes; dusk blocks the call before it reaches the app.3

this is a separate setup from anthropic's connectors directory. dusk bot does not store the provider tokens for these connections; composio holds them, and Disconnect revokes the grant upstream. when comparing instructions, first check which product's connection screen they describe.3

twenty app tasks to consider in dusk bot

here are twenty small reading jobs dusk bots can do with connected apps. anthropic's directory may offer different ones. choose the ones your actual work needs.

  • gmail: find messages for one sender before writing a follow-up list.4
  • google calendar: find the event you need to prepare for.5
  • google drive: find a source file by name before asking for a summary.6
  • google sheets: read a spreadsheet range for a small status check.7
  • slack: search messages for a decision you need to trace.8
  • notion: search pages and databases for the right project home.9
  • github: list issues assigned to you for a work review.10
  • linear: list a team's issues before planning the next discussion.11
  • figma: retrieve file data for a design handoff check.12
  • stripe: list invoices for a billing review, without taking a payment.13
  • hubspot: list contacts for a review of your contact records.14
  • airtable: list records from the table you want to inspect.15
  • asana: get tasks for a status summary.16
  • outlook: list messages when your work inbox lives there.17
  • canva: list your designs to locate the right asset.18
  • salesforce: search contacts before preparing account notes.19
  • youtube: list channel videos for a content inventory.20
  • jira: search issues for a focused project review.21
  • excel: list worksheets before choosing the one to read.22
  • discord: list your server memberships for an account review.23

connect fewer things, then test the result

begin with a question you can answer by reading one app. check whether the bot used the right account and material. connect another app only when that job needs it. a long list of available services is not a reason to give a bot access to all of them.

if your problem is repeated formatting or a method the ai keeps forgetting, skills address a different need. more app access will not repair unclear instructions. keep an explicit source and destination in each request so you can tell where information came from and where the result will go.

write access is a separate choice

in dusk bot, sends such as emails, messages, posts and payments ask first unless you choose a daily amount the bot may send on its own. a bot on Full access with no sending rule of its own may send up to 25 a day without asking, so set Ask every time for it. the sending setting doesn't cover changes like labels or page edits. to keep them supervised, give the bot read-only access or write "ask me before you change anything" into the job.324

if a connection is not working, check which product you connected it in, which account you selected and whether that bot is allowed to use it. avoid broadening access just to make an unclear error disappear. the right connection with a small permission set is easier to inspect than several overlapping ones.

questions

why are my claude connectors not working?

first check the connector's own directory entry for availability and supported actions. if you are using dusk bot, inspect its separate Connected apps setup and the access allowed for that bot.13

do claude connectors need a paid plan?

anthropic's pricing page marks connectors yes on free, pro, max and ultra as of 12 november 2026. check the individual connector entry for its availability.12

can i connect multiple gmail accounts in dusk bot?

yes. dusk bot supports up to five usable accounts per app, each with a label. name the intended account in the task rather than leaving the bot to guess.3
