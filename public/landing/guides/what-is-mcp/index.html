what is mcp, and why would a bot need it?

mcp stands for model context protocol. it is an open-source standard for connecting ai applications to external systems. in everyday terms, it gives an ai app a common way to reach tools and data outside the chat. it is a connection standard, not an ai model or a safety certificate. which server you add, and what it can reach, still matter.1

by the dusk bot team · checked 12 november 2026 · how we made this

the three pieces to keep straight

think about the connection in three parts: the ai application you talk to, an mcp server that exposes a particular system, and the underlying files or service you want to use. the server is the connecting piece. adding one does not mean you have changed the model doing the thinking.

the official mcp introduction defines the protocol as an open-source standard for connecting ai applications to external systems. anthropic introduced and open-sourced it on 25 november 2024. on 9 december 2025, anthropic donated mcp to the agentic ai foundation under the linux foundation.123

what that means for an ordinary task

suppose you want help with material that lives outside the chat. first ask where that material lives and whether the app already has a way to reach it. mcp may be the connection method, but the actual server determines which tools or data are available.

before adding a server, write down the one task you want it for. then inspect what the server says it exposes. if your task needs reading and the proposed connection offers broad changes, stop and work out how to restrict it. a common protocol does not make every server equivalent, and a familiar service name does not identify who operates a particular server.

how dusk bot uses mcp

dusk bot lets you add an mcp server under Plugins, MCP servers. its docs say to add only servers you trust. use that route when you have chosen a trusted server for the system you need.4

dusk bot also has Connected apps, which connect through composio. those connections let you select which bots may use an app and whether each bot may read or also write. do not assume those composio controls describe every mcp server's permissions. check the server and its own access before connecting it. the claude connectors guide separates anthropic's connectors from dusk's connected apps.4

questions to answer before adding a server

  1. who operates it? know whose code or service you are choosing to trust.
  2. what does it reach? a single folder, one account or a wider workspace are different decisions.
  3. what actions does it expose? distinguish reading from changing and sending.
  4. what credentials does it need? do not paste a key into a chat because an unfamiliar instruction asks for one.
  5. how will you remove access? find that path before the connection becomes part of a routine.

if an answer is unclear, leave the server out while you investigate. you can still begin with files you intentionally attach. mcp itself won't ask you before anything happens; these questions are your check.

a skill solves a different problem

if the problem is how the work gets done rather than what the ai can reach, see claude skills.

what mcp does not promise

it does not tell you that a result is accurate, that a server is trustworthy or that your account grants are narrow enough. it also does not make an ai provider's terms irrelevant. check the terms of the ai app and service you use.

start with a reading task, inspect which material was used, and keep private or irreversible work out of the first trial. the computer-use safety guide helps you think about supervision across tools. mcp names how systems connect; you still decide what work belongs on that connection.

questions

do i need to know mcp to use connected apps?

no. for dusk bot's connected apps, open Connected apps, sign in on the app's own page and choose the bots that may use it. adding an mcp server is a separate option under Plugins.4

is mcp a claude-only feature?

no. the official definition describes a standard for connecting ai applications to external systems.1

does an mcp server make my bot safe?

no. review who operates it, what it exposes and what you authorize. dusk bot's guidance is to add only servers you trust.4
