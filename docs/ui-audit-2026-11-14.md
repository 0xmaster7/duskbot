# Desktop app UI audit, 2026-11-14

Every settings page, bot panel tab, dialog, first-run step and chat state the galleries can open, captured in light
(`grok`) and dark (`grok-dark`) at the desktop size (1280x860, chat 1100x900) and the smallest window (768x520,
`electron/window-state.cjs` MIN_BOUNDS). About 300 screenshots, judged against the brand rules: borderless tonal
contrast, no stray shadows, original type weights, calm and quick motion (one dialog motion, one popover motion),
sentence case with "dusk bot" lowercase, inputs in the app's field style, one spacing scale, no overlaps, short copy.

How to capture again:

```
DUSK_UI_E2E=1 DUSK_SURFACES_SKINS=grok,grok-dark DUSK_SURFACES_VIEWPORTS=desktop,min DUSK_SURFACES_ENDS=1 \
  pnpm exec vitest run scripts/testing/surface-gallery.e2e.test.ts
DUSK_UI_E2E=1 DUSK_GALLERY_SKINS=grok,grok-dark DUSK_GALLERY_VIEWPORTS=desktop,min DUSK_GALLERY_MODES=still \
  pnpm exec vitest run scripts/testing/chat-gallery.e2e.test.ts
pnpm ui:baseline            # the key surfaces against the approved set (scripts/testing/visual-baseline)
```

"Before" pictures are in `docs/ui-audit-2026-11-14/before/`. "After" pictures are the approved baseline in
`scripts/testing/visual-baseline/` (same names, `-grok-dark` for dark, `-min` for the smallest window).

## Visual baseline

`scripts/testing/visual-baseline.ts` (`pnpm ui:baseline`) captures 20 key surfaces and 3 chat transcripts in light
and dark at both sizes, and diffs each against the approved picture in `scripts/testing/visual-baseline/`. A shot fails
when more than 0.2% of its pixels move by more than 24 levels in any channel; a diff picture (changes in magenta) goes
to `<capture dir>/visual-diff/`. Approve a wanted change with `pnpm ui:baseline -- --diff-only --approve <names>`.
