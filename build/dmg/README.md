The macOS install window art (660 x 400 pt) is drawn in code around the `dmg.contents` icon centres in `build/electron-builder.yml`, from the shared pixel scene kit in `build/art/pixel-scene.mjs`. `DMG_SCENES` holds the looks (meadow, bridge, dusk, mascots, mascotsText) and `DEFAULT_DMG_SCENE` picks the shipped one. Run `node build/dmg/render.mjs` to rewrite `build/background.png` and `build/background@2x.png` (electron-builder pairs them into a retina TIFF); `--options <dir>` also writes every look for comparison.
