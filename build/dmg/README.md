The macOS install window art (720 x 440 pt) is drawn in code around the `dmg.contents` icon centres in `build/electron-builder.yml`, from the shared pixel scene kit in `build/art/pixel-scene.mjs`. After changing either, run `node build/dmg/render.mjs` to rewrite `build/background.png` and `build/background@2x.png`; electron-builder pairs them into a retina TIFF.
